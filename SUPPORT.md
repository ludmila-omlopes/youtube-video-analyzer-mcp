# Support

If the server does not work as expected, start with [docs/troubleshooting.md](docs/troubleshooting.md).

When reporting an issue, include:

- package version;
- Node.js version;
- operating system;
- MCP client name and version, if relevant;
- which tool failed;
- whether `get_youtube_analyzer_capabilities` reports `ytDlpAvailable`, `ffmpegAvailable`, and `tempDirWritable`;
- sanitized logs or error output;
- a public YouTube URL that reproduces the issue, when possible.

Do not share API keys, private videos, private transcripts, or confidential content in public issues.
